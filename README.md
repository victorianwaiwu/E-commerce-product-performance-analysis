-commerce Product Performance Analysis

Project Overview

This project uses Microsoft Power BI to explore e-commerce product performance, including sales by category, top-performing products, monthly sales trends, customer ratings, and average product prices.

The goal is to turn product data into an interactive dashboard that helps users explore performance indicators and identify patterns.

Tools Used

* Microsoft Excel — data inspection and preparation
* Power Query — data cleaning and transformation
* Microsoft Power BI — dashboard development and visualisation

Dashboard Features

* KPI cards for total sales, product count, average rating, and average price
* Sales distribution by product category
* Category-level sales comparisons
* Top 10 products by sales
* Monthly sales trends
* Interactive category filtering

Key Findings

The dashboard currently displays total sales of approximately $6.0 million and an average product rating of 3.03.

The category comparisons and other findings will be validated against the underlying data before being used to make business recommendations.

Skills Demonstrated

* Dashboard design
* KPI reporting
* Data preparation
* Communicating business information through charts
